바트·엔·동에 환율까지… 엑셀 켜고 계산기 두드리던 그 밤, 이제 끝낼 시간입니다. 무료 도구 ‘골프총무’로 1인당 금액 자동 계산부터 카톡 공유, 입금 확인까지 한 번에.

“총무 한 번 해본 사람은 압니다”

4명이 태국으로 3박 4일 골프를 다녀왔습니다. 그린피는 바트로 긁고, 카트비는 현장에서 현금, 숙소는 카드로 한 명이 결제, 회식비는 또 다른 사람이… 돌아오는 비행기 안에서 깨닫죠. “이거 정산 내가 다 해야 하는구나.”

집에 와서 엑셀을 켭니다. 영수증을 모으고, 그날그날 다른 환율을 검색해서 원화로 바꾸고, “이건 다 같이 낸 거”, “이건 OO만 친 거”를 구분해서 더하고 나누고… 한 시간쯤 지나면 머리가 지끈합니다. 게다가 카톡에 정리해서 올리면 “나 얼마 보내면 돼?”, “계좌 다시 알려줘”가 또 한참 이어집니다.

골프총무가 뭔가요?

골프총무는 4인 내외 해외 골프 여행의 총무(모임 리더)를 위해 만든 무료 정산 도구입니다. 설치할 앱도, 복잡한 사용법도 없습니다. 브라우저에서 주소만 열면 끝. 핵심은 단 하나 — “여행지 통화로 입력하면, 원화 1인당 금액이 자동으로 나온다.”

  • 💱 실시간 환율 자동 환산 — 바트·엔·동·페소를 그날 시세로 원화 변환
  • 🧮 항목별 1인 · 팀(N빵) — “각자 낼 것”과 “다 같이 N분의 1” 자동 구분
  • 👥 개인별 정산 — 누가 얼마 내야 하는지 사람별로 딱
  • 📤 카톡 공유 링크 — 일행은 링크만 누르면 자기 금액·계좌 확인
  • ✅ 입금 확인 — 입금 들어오면 체크, 전원 완료되면 자동 정리

“그냥 계산기랑 뭐가 달라요?”

계산기는 환율을 모릅니다. 그리고 계산기는 “이 비용은 4명이 N빵, 저 비용은 2명만” 같은 걸 구분 못 합니다. 골프총무는 항목마다 1인 / 팀(N빵) / 특정인을 토글 한 번으로 정해두면, 팀 비용은 인원수로 자동 분배하고, 특정인 비용은 그 사람에게만 더합니다. 여기에 환율까지 자동이니, 총무가 손으로 할 계산이 사실상 0이 됩니다.

💡 실제 예시 — 태국 방콕 4인 골프

항목 금액 부담 1인당(원)
그린피6,000฿각자≈ 246,000
카트·캐디1,300฿각자≈ 53,300
숙소(2박)12,000฿팀 N빵≈ 123,000
렌터카+기사8,000฿팀 N빵≈ 82,000
회식5,000฿팀 N빵≈ 51,200
👉 한 사람당 보낼 돈≈ 555,500원

※ 1฿ ≈ 41원 가정. 환율은 실시간으로 자동 적용되며 직접 수정도 가능합니다. “각자”는 본인 것만, “팀 N빵”은 4명으로 나눠 더해집니다 — 이 계산을 총무가 안 해도 됩니다.

써보면 이렇게 쉽습니다 (5단계)

1️⃣ 가입하고 ‘새 여행’ 만들기

이메일로 가입(무료) 후 여행 이름·국가·기간·일행 이름을 입력합니다. 국가를 고르면 통화는 자동으로 잡힙니다.

📸 [캡처 ②] 새 여행 만들기 (국가·기간·일행 입력) — 제안 파일명: 02-new-trip.png

2️⃣ 비용 항목 입력 (1인/팀 토글)

‘그린피 6000바트’처럼 항목과 금액을 넣고, 각자 낼 건지 다 같이 N빵 할 건지 토글로 정합니다. 여러 줄을 한 번에 붙여넣어 자동 입력도 됩니다.

📸 [캡처 ③] 비용 항목 + 1인/팀(N빵) 토글 — 제안 파일명: 03-rows.png

3️⃣ 환율 자동 → 1인당 즉시 계산

입력하는 순간 실시간 환율로 원화 환산이 반영되고, 1인당 금액과 전체 합계가 실시간으로 바뀝니다. 환율이 다르면 직접 고칠 수도 있어요.

📸 [캡처 ④] 실시간 환율 + 1인당 자동 계산 — 제안 파일명: 04-fx.png

4️⃣ 개인별 정산 확인

일행 이름을 넣어두면 사람마다 내야 할 총액이 나옵니다. “누가 얼마”가 한눈에.

📸 [캡처 ⑤] 개인별 정산 (사람별 금액) — 제안 파일명: 05-settlement.png

5️⃣ 카톡 공유 → 일행이 바로 송금

‘결과 링크 공유’를 누르면 읽기 전용 정산 페이지 링크가 만들어집니다. 카톡에 붙여넣으면 일행은 로그인 없이 자기 미지급 금액을 확인하고, ‘계좌·금액 복사’ 버튼으로 토스 등에 붙여넣어 바로 송금합니다. 입금이 들어오면 총무가 ‘입금완료’ 체크 — 전원 완료되면 자동으로 정리됩니다.
